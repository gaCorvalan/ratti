# Ratti

Ratti es una app Android **solo para mirar** las finanzas de Gabriel. Lee la planilla de Google Sheets de Finni, nunca escribe en ella, y no se publica en tiendas.

## Convenciones

- PRs chicos.
- Una línea por PR en `CHANGELOG.md`.
- Textos de UI en español rioplatense.
- El "mes" es el ciclo de tarjeta y se muestra como "Noviembre, cierra el 26/11", nunca AAAA-MM.
